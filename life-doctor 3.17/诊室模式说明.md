# 诊室模式说明（2.5 · 账号 / 医誉版）

> 工程目录：`D:\新建文件夹\live-doctor 2.5`　｜　急诊室版本：`D:\新建文件夹\live 2.5`
> 账号与急诊室版共用 `lifesim.accounts.v1`：同一浏览器下两个版本的账号、战绩、医誉互通。

## 1. 时间与排班

| 项目 | 规则 |
|---|---|
| 白班 | **48 分钟**（1× 速度下等于现实 48 分钟；2×/4×/8× 同步加速） |
| 夜班 | **48 分钟**，与白班等长 |
| 班次 | 第 1 天 **白班**，第 2 天 **夜班**，交替；状态条显示「白班 / 夜班」 |
| 休息 | 每位病人治疗结束（治愈或死亡）后 **2–8 分钟**随机休息；**休息期间本班计时暂停**（48 分钟都是接诊时间） |
| 接诊 | 点击「开始今天的门诊」后自动接诊第一位；之后由候诊区依次进入 |
| 病人类型 | **一律随机**（不再提供分类挑选）：白班候诊 10 人、普通病与中暑多；夜班候诊 4 人、以急危重为主 |
| 本班结束 | 48 分钟归零时自动交班：正在诊疗的病人记为「转交」，弹出日结算 |

## 2. 库存：药品 + 手术耗材

- **常用药 40 份，其他药 10 份，手术耗材 8 份**（每日开始重置）。
- 每份 = 一个最小包装（瓶 / 支 / 袋 / 包），在 `js/data-stock.js` 中定义 `per`（每份量）与 `price`（单价）。
- 药品消耗：

```
份数 = ceil(输入剂量 / 每份量)
```

| 药品 | 每份量 | 输入 | 消耗 |
|---|---|---|---|
| 肾上腺素 | 1 mg | 0.5 mg 静推 | 1 份 |
| 阿司匹林 | 100 mg | 300 mg 嚼服 | 3 份 |
| 生理盐水 | 500 mL | 1000 mL 静滴 | 2 份 |
| 头孢曲松 | 1 g | 2 g 静推 | 2 份 |

- **手术耗材**按「术式 + 部位」自动扣减，缺任何一项都**无法开台**：

| 术式 | 必耗 |
|---|---|
| 切除术 / 摘除术 | 无菌手术包、手套、麻醉耗材、缝线套件、止血材料 |
| 吻合术 / 分流术 | + 一次性吻合器、缝线套件 |
| 缝合修补 / 结扎止血 | 缝线套件（结扎另加止血材料） |
| 引流 / 减压 / 造口 | 引流管套件 |
| 清创 / 冲洗 / 探查 | 冲洗液与吸引管 |
| 固定 / 复位 | 骨科钢板螺钉 + 骨水泥 |
| 置换 / 移植 | 血管器械 + 骨水泥 |
| 活检 / 内镜 / 介入 | 内镜介入耗材 |
| 颅脑部位 | 开颅 / 颅钻套件 |
| 胸腔、心脏、纵隔、气道、膈肌、大血管 | 胸腔闭式引流套件（血管另加血管器械） |

## 3. 经费、采购与医誉福利

- 每天 **¥12,000**，日结算显示支出与结余；下一天重置。
- 药房可采购**药品与手术耗材**：`1 / 3 / 5 / 10` 份一键下单；下单立即扣经费，**1–5 分钟送达**，送达才入库。
- **医誉折扣**：等级越高，药品与耗材越便宜（最新价格直接显示，原价划掉）。
- **配送提速**：医誉等级提供 1.05–1.45 倍配送速度；**副主任医师及以上在白班高峰期（高峰班）享优先配送**，配送时长再乘 0.55。

## 4. 医师账号与医誉等级

| 等级 | 医誉要求 | 药品/耗材 | 配送 | 高峰期优先 |
|---|---|---|---|---|
| 见习医士 | 0 | 无折扣 | 1.00× | — |
| 住院医师 | 100 | 98 折 | 1.05× | — |
| 主治医师 | 300 | 96 折 | 1.10× | — |
| 副主任医师 | 700 | 93 折 | 1.15× | ✓ |
| 主任医师 | 1300 | 90 折 | 1.20× | ✓ |
| 学科带头人 | 2200 | 87 折 | 1.28× | ✓ |
| 院长 | 3500 | 84 折 | 1.36× | ✓ |
| 杏林国手 | 5500 | 80 折 | 1.45× | ✓ |

**医誉获取**：治愈一位病人 +10~+18（按单例评分），死亡 −6，全班治愈≥死亡额外 +8~+20 全勤奖。医誉按账号累计，升级时弹提示并立即生效。

**账号**：
- 注册 / 登录 / 游客三种状态；密码仅做本地加盐哈希，不是服务器认证。
- 登录后战绩、医誉、门诊进度都按账号保存；游客只保存在本机游客档案。
- **保持账号**（登录时勾选）：写入 12 小时免密凭证，12 小时内再次打开直接进入，无需密码；取消勾选则关闭浏览器后需要重新登录。
- **跨版本账号追回**：① 自动扫描本机所有 `lifesim.*` 存档（含旧版键名）并合并；② 也可把「账号码」粘贴到另一台机器 / 另一个版本的诊室版里恢复。
- **退出自动存档**：关闭页面 / 切到后台时保存本班进度（天数、班次、剩余时间、经费、库存、在途采购、战绩），下次打开弹「继续上次门诊」并恢复。

## 5. 清单与治愈逻辑（两个版本一致）

1. 完成必需处置后 `d.controlled = true`，只表示「病因已处理」。
2. **只有循环/氧合/体温/血钾达到可恢复条件**（MAP > 60、SpO₂ > 88、有脉搏、体温 33–40℃、K⁺ < 7、乳酸 < 6），疾病偏移才回退。
3. 仍不稳定时日志提示「病因已处理，但循环/氧合仍不稳定」，不会转归。
4. 支持治疗型病例（无 `need` 项）需**至少 2 项**对症处置 + 连续稳定。
5. 转归需连续稳定 **45 秒**（慢性病 75 秒），中途恶化超过 2.5 秒重新计时。

## 6. 界面

- **诊室状态条**：第几天、白班/夜班、倒计时与进度条、经费、**医誉等级与折扣**、候诊人数、休息/诊疗状态、库存告急计数。
- **顶栏账号徽标**：姓名 + 医誉等级，点击打开账号弹窗（资料、医誉进度条、福利、退出）。
- **药房 / 库存**：药品 / **手术耗材** / 库存≤10 / 常用药 四个页签，折扣价与在途配送。
- **候诊区 / 休息覆盖层 / 日结算**（新增「本班医誉」）。

## 8. 验证要点

- 时间：白班 / 夜班各 48:00 起算；休息 2–8 分钟且计时暂停，跳过休息立即恢复倒计时。
- 采购：经费 12000 → 11600（肾上腺素 5 份），生成 1–5 分钟在途配送；高医誉账号显示折扣价（93 折时 ¥80 → ¥74）。
- 耗材：开一台阑尾切除术，无菌手术包 / 手套 / 麻醉耗材 / 缝线各 −1、止血材料 −2；库存不足时开台被拦截并提示补货。
- 医誉：治愈 +10~18，死亡 −6，全班结算另加全勤；升级后药房价格与状态条立即更新。
- 账号：登录后关闭再打开（勾选保持账号）直接进入；过期凭证回落到游客；旧键名账号可一键追回。
- 进度：关页面后重开，状态条显示「第 N 天 · 白班 · 剩余 xx:xx · 经费 ¥xxxx」。
